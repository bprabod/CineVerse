# CineVerse

A responsive movie-discovery homepage inspired by modern streaming platforms. Built with plain HTML, CSS, and JavaScript.

## Features

- Dark cinematic layout with a featured hero section
- Trending, popular movie, and series carousels
- Search by title, genre, or year
- Movie detail dialog and demo watchlist interaction
- Responsive desktop and mobile layouts
- Keyboard-accessible movie cards and reduced-motion support

## Run locally

No build tools or dependencies are required. Open `index.html` in a browser, or serve the folder with a local static server.

## Customize

- Edit the title data and poster URLs in `script.js`.
- Change colors, spacing, and responsive rules in `style.css`.
- Update the page structure in `index.html`.

Movie artwork is loaded from TMDB image URLs for demonstration purposes. CineVerse is an independent concept project and is not affiliated with Netflix or TMDB. The newsletter and watchlist interactions are front-end demos and do not store or submit user data.

## Deploy

Enable GitHub Pages for this repository and select the `main` branch with the root folder as the source.
